# Security Policy

## Supported Versions

Currently, only the latest release and the `main` branch receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report it via:
- GitHub's **Private Vulnerability Reporting** feature in the [Security Advisories](../../security/advisories/new) tab, or
- Email directly to: `1866universe@gmail.com`

Please include the following details in your report:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept (PoC)

You will receive an initial response acknowledging the report within 48 hours. Valid vulnerabilities will be patched promptly.
